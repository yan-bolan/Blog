I have set up a public MicroBin server at [https://pub.microbin.eu.](https://pub.microbin.eu./) This will be available for as long as my Raspberry Pi 4 can handle the traffic. A public server browser is also coming soon.  
我已经在 https://pub.microbin.eu 搭建了一个公开的 MicroBin 服务器 [。](https://pub.microbin.eu./) 只要我的树莓派 4 能应付流量，这个功能就会一直用。公共服务器浏览器也即将推出。

Or install it manually from [Cargo](https://crates.io/crates/microbin):  
或者从 [Cargo](https://crates.io/crates/microbin) 手动安装：

```
cargo install microbin;curl -L -O https://raw.githubusercontent.com/szabodanika/microbin/master/.env;source .env;microbin
```
