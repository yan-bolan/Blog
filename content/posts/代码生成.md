[swagger-api/swagger-codegen: swagger-codegen contains a template-driven engine to generate documentation, API clients and server stubs in different languages by parsing your OpenAPI / Swagger definition. (github.com)](https://github.com/swagger-api/swagger-codegen#compatibility)

# Download current stable 3.x.x branch (OpenAPI version 3)

wget https://repo1.maven.org/maven2/io/swagger/codegen/v3/swagger-codegen-cli/3.0.41/swagger-codegen-cli-3.0.41.jar -O swagger-codegen-cli.jar
java -jar swagger-codegen-cli.jar --help

有java环境即可;

java -jar swagger-codegen-cli.jar generate  -i swagger.json  -l typescript-axios -o ./result
